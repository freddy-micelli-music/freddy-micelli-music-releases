# Freddy Micelli Music

Lecteur musical pour Mac Intel et Apple Silicon, macOS Sonoma 14 ou plus récent.

## Télécharger

[Télécharger la dernière version](https://github.com/freddy-micelli-music/freddy-micelli-music-releases/releases/latest)

Décompressez le ZIP et placez **Freddy Micelli Music.app** dans **Applications**.

À partir de la version 1.1.6, le lecteur vérifie les mises à jour au démarrage. Un indicateur sous le menu de l’égaliseur signale une nouvelle version ; cliquez dessus pour la consulter et choisir de l’installer. La signature des mises à jour est vérifiée avant extraction.

Les versions 1.1.5 et antérieures nécessitent une installation manuelle de la version 1.1.6 une fois.

## Spotify et volume

Le mode **Spotify externe** ouvre les albums et les recherches dans Spotify avec le compte de l’utilisateur. Les commandes d’écoute restent dans Spotify.

Le mode intégré dépend des autorisations imposées par Spotify. Aucun compte de l’artiste n’est nécessaire pour le mode externe.

Le menu sous la molette permet de choisir **Volume du lecteur / écran HDMI** pour les fichiers et les radios. Le réglage matériel de l’écran reste indépendant.

## Distribution macOS

Cette version possède une signature locale et n’est pas notarifiée par Apple. macOS peut en bloquer l’ouverture sur un autre Mac.

Ce dépôt contient les téléchargements et le flux de mise à jour, pas le code source du projet ni les clés privées.
